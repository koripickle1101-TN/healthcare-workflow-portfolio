# Responsible AI Healthcare Operations Study Tool

An interactive Streamlit study tool created for Kori Pickle's Healthcare Operations Intelligence portfolio.

## Purpose

This tool teaches responsible AI, sustainability, strategic foresight, systemic risk, ethical governance, responsible innovation, and long-term value creation through a healthcare operations lens.

It is designed for learning and portfolio demonstration only. It uses simulated educational content and no PHI.

## Study Modes

- Home dashboard
- 8-module study path
- Flashcards
- Knowledge check quiz
- Responsible AI governance checklist
- Portfolio section generator
- LinkedIn post generator
- Capstone framework export

## Brand Identity

- White background: `#FFFFFF`
- Tennessee Orange: `#FF8200`
- Black typography
- Editorial serif headlines
- Clean sans-serif supporting text
- Double-ring workflow nodes
- Premium healthcare operations visual structure

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud Deployment

1. Go to Streamlit Community Cloud.
2. Select this GitHub repository.
3. Set the app path to:

```text
responsible-ai-healthcare-study-tool/app.py
```

4. Deploy.
